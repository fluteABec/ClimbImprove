# ClimbImprove

## 🎯 À propos du projet

ClimbImprove est une présentation interactive innovante présentant un concept de système d'entraînement d'escalade intelligent. Cette présentation web démontre comment l'analyse vidéo basée sur l'IA et les prises connectées intelligentes peuvent révolutionner l'expérience d'entraînement en escalade.

### Fonctionnalités présentées :

- **Analyse vidéo par IA** : Suivi des mouvements et analyse technique en temps réel
- **Prises connectées intelligentes** : Prises IoT qui mesurent la force de préhension et le positionnement
- **Entraînement personnalisé** : Programmes d'entraînement adaptés au niveau de chaque grimpeur
- **Suivi des performances** : Analytiques détaillées et suivi de la progression
- **Interface interactive** : Design moderne et responsive construit avec React et Tailwind CSS

## 📥 Installation

### Prérequis

- Node.js (v18 ou supérieur)
- npm ou yarn

### Étapes

1. **Cloner le dépôt**
   ```bash
   git clone https://github.com/fluteABec/ClimbImporve.git
   cd ClimbImporve
   ```

2. **Installer les dépendances**
   ```bash
   npm install
   ```

3. **Démarrer le serveur de développement**
   ```bash
   npm run dev
   ```

4. **Ouvrir dans le navigateur**
   
   L'application sera disponible sur `http://localhost:3000` (ou un autre port si le 3000 est utilisé)
